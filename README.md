# What Is Scoutmaster?

Scoutmaster is a revolutionary First Tech Challenge scouting tool developed by FTC Team #16423. It is jam-packed with features that will help your team compete better and stronger at all your competitions.

This is right now being developed as a 2.0 to the original Scoutmaster, and this will have a better UI and many new features. If you want to use the original Scoutmaster right now, you can go to this [link here!](https://storm16423.ca/Scoutmaster/)

## 🌟Features🌟

- Compatible with all devices! 📱 💻
- Realtime syncing across all devices! 🔗
- Prescout teams before matches to figure out unique details about each team! 🔎
- Scout matches to know <u>_EXACTLY_</u> how many points each team scores! 📏 📐
- Get a summary afterwards of that data to help with alliance selection! 📋 🗃️

## Disclaimer

This is a readme based on the planned features for this tool, the 2.0 is not out yet, the original can still be used though and contains many, but not all of these features.
